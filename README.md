# 힘찬짐 백엔드

NestJS와 PostgreSQL로 PT 이용권과 예약을 관리합니다. 회원 웹과 직원용 어드민이 같은 API를 사용합니다.

## 실행

Node.js 22 이상이 필요합니다.

```bash
npm ci
cp .env.example .env
npm run migrate
npm run seed
npm start
```

`.env`에 기존 Render DB의 접속 주소와 초기 계정 비밀번호를 설정한 다음 실행합니다. `migrate`는 `hw2`에만 테이블을 만듭니다. 같은 이름의 테이블이 있으면 중단하며 기존 테이블을 지우지 않습니다. `seed`도 기존 계정이 있으면 중단합니다.

`SEED_ADMIN_EMAIL`은 초기 관리자 이메일입니다. `SEED_ADMIN_PASSWORD`, `SEED_MEMBER_PASSWORD`, `SEED_TRAINER_PASSWORD`는 각각 관리자, 가상 회원, 가상 트레이너의 비밀번호입니다. 10자 이상이어야 하며 GitHub에 올리지 않습니다.

가상 회원은 `member1@example.test`부터 `member3@example.test`까지, 트레이너는 `trainer1@example.test`와 `trainer2@example.test`입니다.

## 인증과 권한

비밀번호는 bcrypt로 해시합니다. 로그인하면 임의 세션 토큰을 발급하고 DB에는 토큰의 SHA-256 해시만 저장합니다. 웹의 Next.js 서버가 원본 토큰을 HttpOnly 쿠키로 보관하고 백엔드에 Bearer 토큰으로 전달합니다.

역할은 고객, 일반 직원, 관리자입니다. 공개 회원가입은 고객 계정만 만듭니다. 직원 생성, 역할 변경, 중지와 비밀번호 리셋은 관리자만 처리할 수 있습니다. 중지와 리셋은 기존 세션을 무효화합니다. 임시 비밀번호는 응답에서 한 번만 제공하며 다음 로그인에서 변경해야 합니다.

## 예약 규칙

정시부터 한 시간씩 예약합니다. 한국 시각으로 평일 06시부터 23시, 주말 09시부터 18시까지 운영합니다. 같은 트레이너나 회원의 같은 시각 예약은 DB의 부분 UNIQUE 인덱스로 막습니다. 취소한 예약은 중복 검사에서 제외합니다.

백엔드는 이용권 행을 잠근 뒤 소유자와 유효기간, 예약 가능한 횟수, 트레이너 근무 요일을 확인합니다. 잔여 횟수는 총횟수에서 완료와 노쇼를 빼고, 새로 예약 가능한 횟수는 여기에서 예약 중인 횟수를 더 뺍니다.

취소는 차감하지 않습니다. 과제 필수 B-10을 따른 구현이며, 선택 규정 문서의 늦은 취소 차감과는 다르므로 고객에게 확인해야 합니다. 이용권은 만료일 당일까지 사용할 수 있습니다. 수업 시작 전에는 완료와 노쇼로 처리할 수 없습니다.

## 검증

```bash
npm test
```

현재 테스트는 PGlite의 PostgreSQL 엔진에서 DB 제약과 API 로직을 확인합니다. 가입, 비밀번호 해시, 권한, 다른 회원 이용권의 사용 차단, 중복 예약, 취소 후 예약 가능 횟수 복구, 완료와 노쇼 차감, 임시 비밀번호 변경, 세션 무효화, 직원 중지, 마지막 관리자 보호를 검사합니다. 실제 NestJS HTTP 서버의 정상 및 인증 실패 응답도 확인합니다.

Render DB에서의 실제 연결과 동시 요청 검증, DBeaver 확인은 별도로 수행해야 합니다. 테스트 환경에서 통과했다는 사실이 배포를 증명하지는 않습니다.

## 배포

Render Node 서비스의 빌드 명령은 `npm ci --omit=dev`, 시작 명령은 `npm start`입니다. DB 마이그레이션과 가상 데이터 입력은 최초 한 번 별도로 실행합니다. 환경변수는 Render 설정에만 넣습니다. `DB_SSL=true`이면 인증서를 검증하는 SSL 연결을 사용합니다. DB 내부 주소를 쓰는 경우에는 Render 내부 네트워크 연결 조건에 맞게 설정합니다.

무료 서비스는 사용하지 않으면 잠들 수 있습니다. 발표 전에 `/health`를 열어 서버를 깨워 둡니다.
